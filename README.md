## 🧠 How jeff Works (In Plain English)

jeff is built on a small but smart language model—just 0.8 billion parameters, which makes it incredibly fast and light. It's designed to do **one thing exceptionally well**: compare options and give you a reasoned pick with a confidence score.

The "0.8B" means it's small enough to run smoothly on a regular laptop, yet smart enough to handle complex trade-offs. And because it's open-source, you can trust what's inside.

### What are LoRA Adapters?

Think of jeff as a base car engine. By itself, it's great. But you can swap in different "tires" (called **LoRA adapters**) to make it excel at specific tasks. For example:

- A **marketing adapter** for choosing between ad copy variations.
- A **logistics adapter** for route or vendor selection.
- A **personal adapter** for everyday decisions like "Which movie should I watch?"

You can download additional adapters from the same releases page and place them in the `adapters` folder next to jeff. No configuration needed—jeff picks them up automatically.

### Is jeff free?

Yes. jeff is completely open-source and free to use forever.

### Do I need a powerful computer?

No. jeff is designed to be lightweight. If your computer can run a web browser smoothly, it can run jeff.

### Can I use jeff offline?

Absolutely. That's the whole point. Once downloaded, jeff never needs an internet connection.

### How do I create my own adapter?

If you're curious (and a bit technical), check the documentation in the repository. But you don't need to—many ready-made adapters are available for download.

### Will jeff work on Mac or Linux?

The current version is built for Windows. Mac and Linux versions may come later.

### What if jeff gives me the "wrong" answer?

jeff gives you probabilities, not orders. It's a tool to *inform* your decision, not replace your judgment. The confidence score helps you know when to trust it and when to think twice.

## 🛠️ Troubleshooting

**Problem:** Windows shows a warning when I run jeff.  
**Solution:** This is common for new software. Click "More info" → "Run anyway." Your PC is safe; it just hasn't seen jeff before.

**Problem:** The window opens but looks blank.  
**Solution:** Make sure you extracted the entire zip folder, not just one file. All files need to stay together.

**Problem:** jeff says "Adapter not found."  
**Solution:** Check that you have at least one adapter file in the `adapters` folder. If the folder doesn't exist, create it right next to `jeff.exe`.

**Problem:** The download is slow.  
**Solution:** The file is large because it contains the full model. Be patient—it's a one-time download.
